A1. Что такое стек вызовов (call stack) в Python и как его увидеть?
Стек вызовов - это структура данных, которая хранит информацию о всех активных вызовах функций в момент выполнения программы. Чтобы его увидеть, необходимо ввести breakpoint() перед нужной строкой

A2. В чем разница между except: и except Exception as e:?
except: все исключения, включая системные (SystemExit, KeyboardInterrupt, GeneratorExit)
except Exception as e: только исключения, наследующие от Exception (все пользовательские и большинство встроенных)

A6. Что такое утечка памяти в Python и как она может возникнуть?
Утечка памяти — это ситуация, когда программа удерживает ссылки на объекты, которые больше не нужны, предотвращая их сборку мусора. Память продолжает расти, пока программа не завершится.
Основные причины утечек в Python: глобальные коллекции без очистки, циклические ссылки, замыкания, незакрытые ресурсы, глобальные кеши

B4. Как использовать tracemalloc для поиска утечек памяти в долгоживущем приложении (например, веб-сервер)?
import tracemalloc
import time

def monitor_memory():
    tracemalloc.start()
    
    # Периодически снимаем снимки
    for i in range(10):
        time.sleep(60)  # Каждую минуту
        
        snapshot = tracemalloc.take_snapshot()
        stats = snapshot.statistics('lineno')
        
        print(f"\nSnapshot {i+1}:")
        for stat in stats[:5]:
            print(f"  {stat}")
