Контрольные вопросы для самопроверки
1. Что такое ER-диаграмма и в чём её преимущество перед текстовым описанием БД?
ER-диаграмма (Entity-Relationship diagram) – это графическое представление логической структуры базы данных. Она позволяет:
•	Наглядно увидеть все таблицы (сущности) и связи между ними.
•	Согласовать структуру БД с заказчиком ещё до написания SQL-кода.
•	Избежать ошибок проектирования (дублирования, несогласованности).
•	Автоматически сгенерировать корректный SQL-скрипт создания таблиц, ключей и ограничений.

2. Какие типы связей существуют? Приведите пример для каждого из своего варианта.
Один ко многим (1:N) 
Многие ко многим (M:N) 
Один к одному (1:1)

3. Что такое нормализация? Для чего нужна 3НФ?
Нормализация – это процесс устранения дублирования данных и аномалий вставки/удаления.
3НФ (третья нормальная форма): нет транзитивных зависимостей (неключевые поля не зависят от других неключевых).
Пример нарушения: в таблице Заказы хранится город_заказчика, хотя он определяется через id_заказчика. Правильно – вынести город в таблицу Заказчики.

4. Как в MySQL Workbench создать связь «многие ко многим»?
Выбрать инструмент N:M Relationship
Кликнуть на родительскую таблицу (ту, на чей PK ссылаются), затем на дочернюю.

5. Что означает флаг AI (Auto Increment)? В каких полях его ставят?
Значение автоматически увеличивается (для PK), ставится в ключевых полях

6. Как экспортировать ER-диаграмму в PDF?
Экспорт в PDF: File → Export → Export as PNG/SVG/PDF → выбрать PDF

7. Для чего нужен внешний ключ? Что произойдёт, если попытаться удалить запись, на которую ссылается внешний ключ (при ON DELETE RESTRICT)?
Ссылается на PK другой таблицы, обеспечивая связь.

8. Как импортировать данные из CSV в таблицу через Workbench?
•	Для своего варианта найдите CSV-файлы (они предоставлены в общей документации, например Продукция.csv, Материалы.csv).
•	В Workbench: кликните правой кнопкой на таблице → Table Data Import Wizard.
•	Выберите CSV-файл, укажите разделитель ; (точка с запятой), кодировку UTF-8.
•	Сопоставьте столбцы CSV со столбцами таблицы.
•	Выполните импорт.
•	Проверьте, что строки добавились: SELECT * FROM ;

9. Какая команда SQL показывает все таблицы в текущей базе данных?
SHOW TABLES;
